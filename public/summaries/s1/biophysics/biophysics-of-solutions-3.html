If you remember only this
  • ω = [1 + α(β − 1)] C (osmol/L). Fully dissociated (α = 1): ω = βC. Non-electrolyte (α = 0 or β = 1): ω = C.
  • β = ions released per molecule: NaCl 2, Na₂SO₄ 3, CaCl₂ 3, H₂SO₄ 3, H₃PO₄ 4, Na₃PO₄ 4, KMnO₄ 2.
  • α (van 't Hoff) = dissociated moles / initial moles: strong electrolyte 1 (HCl), weak < 1 (HCOOH), non-electrolyte 0 (glucose).
  • Several solutes: ω = Σ ωi. Osmolality: same formula with molality (mol/kg of solvent) → osmol/kg.

β and α slide 16

β — number of ions Ions produced by the dissociation of one molecule of an electrolyte.
NaCl → Na⁺ + Cl⁻ ⇒ β = 2
Na₂SO₄ → 2Na⁺ + SO₄²⁻ ⇒ β = 3
Non-electrolyte (urea, glucose): β = 1 ⇒ ω = C
α — van 't Hoff dissociation coefficient α = ndissociated / ninitial, 0 ≤ α ≤ 1
HCl, strong electrolyte: α = 1
HCOOH, weak electrolyte: α < 1
Glucose, non-electrolyte: α = 0

Exercise 5 (slides 17–18) 1 L of water + 5.85 g NaCl + 18 g glucose (180 g/mol).
NaCl: C = 5.85 / (58.5 × 1) = 0.1 mol/L, α = 1, β = 2 → ω = 0.2 osmol/L. Glucose: C = 18/180 = 0.1 → ω = 0.1 osmol/L.
ω = 0.3 osmol/L = 300 mosmol/L (same as plasma, see part 4).

Exam method — osmolarity of a mixture every year, Q6

  1. Moles of each solute in the solution: grams → n = m/M; a volume of stock acid → n = V(L) × C.
  2. Divide by the solution volume (usually 1 L) → Ci.
  3. Find β (count the ions) and α (given; "totally dissociated" = 1).
  4. ωi = [1 + α(β − 1)] Ci; add them up.

Traps
  • With α < 1, don't just multiply by β: use 1 + α(β − 1) (Na₃PO₄: 1 + 0.6 × 3 = 2.8, not 0.6 × 4).
  • H₃PO₄ "totally dissociated" → 3H⁺ + PO₄³⁻ → β = 4.
  • Answers are often in mosm/L: × 1000.

F. Types of vessels and membranes slide 18

  • 5 types of blood vessels: arteries, arterioles, capillaries, veins, venules.
  • Blood: heart → (arteries) → organs → (veins) → heart.
  • Gases and nutrients: blood ↔ (capillaries) ↔ tissues.

Self-check — answer, then tap to reveal

Osmolarity of 0.1 mol/L Na₂SO₄, fully dissociated?
β = 3, α = 1 → 0.3 osmol/L.
α for HCl, HCOOH, glucose?
1 (strong), < 1 (weak), 0 (non-electrolyte).
Osmolarity vs osmolality?
Per litre of solution (osmol/L) vs per kg of solvent (osmol/kg).
0.65 mol/L Na₃PO₄ with α = 0.6: ω?
0.65 × (1 + 0.6 × 3) = 1.82 osmol/L.
For which solutes is ω = C?
Non-electrolytes (β = 1), e.g. urea, glucose.
Name the 5 types of blood vessels.
Arteries, arterioles, capillaries, venules, veins.
5.85 g NaCl + 18 g glucose in 1 L: ω?
0.2 + 0.1 = 0.3 osmol/L = 300 mosmol/L.
β of H₂SO₄ and H₃PO₄?
3 (2H⁺ + SO₄²⁻) and 4 (3H⁺ + PO₄³⁻).
