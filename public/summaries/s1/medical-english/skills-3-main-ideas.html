If you remember only this
  • Medical reading is hierarchical, not linear: macro (global meaning/topic) → meso (explanations, causes, mechanisms) → micro (data, examples, evidence).
  • Main idea = semantic nucleus; can be explicit (topic sentence), implicit (inference) or distributed (across sentences).
  • 5 kinds of supporting detail: causal explanation (because, due to), clinical evidence (studies show), descriptive (includes, consists of), exemplification (for example, such as), comparative (whereas, unlike).
  • Paragraph: opening → development → support → closure (not always linear).
  • Tests: deletion, substitution, question (why? how? example?), highlighting. Summarize: key terms → remove examples → merge → reformulate.

2.1 & 5. The main idea (macro-structure) p. 4–5, 7

  • Identifying it = top-down processing (global meaning before details). Typical functions: a definition, a clinical statement, a scientific claim, a diagnostic classification.
  • Missing it → fragmented understanding (focus on symptoms/numbers without the clinical proposition).

4. Structure of a medical paragraph p. 6

Opening — main idea / definition→Development — mechanisms / processes→Support — studies / data→Closure — synthesis / implication

"Expository medical discourse structure" — but not always linear: in research articles the main idea may come at the end or be distributed.

Main ideas = macro-propositions (essential); details = micro-propositions (enrich but not needed to rebuild the central meaning).

9–10. Reconstructing the main idea in a summary p. 10–11

  1. Identify key terms → lexical core.
  2. Remove examples → reduce noise.
  3. Merge concepts → conceptual synthesis.
  4. Reformulate the sentence → academic summary.

"COPD is a lung disease causing airflow limitation due to smoking." → "COPD is a progressive respiratory condition characterized by restricted airflow." Uses abstraction, generalization, semantic integration. Benefits: lecture comprehension, note-taking, exam revision, writing synthesis, critical reading.
